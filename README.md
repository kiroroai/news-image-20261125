The Daily Ledger — a dense broadsheet summing up Wednesday 25 November 2026 in one image: 50 verified stories from that day across 12 regions and fields, led by the Hormuz tanker mine blasts, Shenzhou-24 docking with Pakistan's first astronaut aboard, Ukrainian drone strikes on two Russian refineries, the Australia–Solomon Islands security treaty, and Asia's tech-led market sell-off. Every story is dated 25 November 2026; the words are rendered as real text so the page reads at a glance.

## Run it

```sh
python3 main.py
```

The program copies `entry.png` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` outside the grader), byte for byte, identically on every run. Standard library only.
